# Security

Pointout is a dev tool. It should never ship to production.
If you find a way it does, or any other hole, tell us quietly.

## Reporting

Use [private vulnerability reporting](https://github.com/pointout/pointout/security/advisories/new).
Please do not open a public issue.

We reply within a week and credit you in the fix unless you say otherwise.

## Supported versions

Only the latest release gets fixes.
